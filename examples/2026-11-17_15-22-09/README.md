# CIS example: 2026-11-17_15-22-09

Selected output frames from the real `2026-11-17_15-22-09` sensor session.

- Source: `cis/stereo.mkv`
- Source layout: `2560x720` side-by-side H.264, 25 fps
- Selected frames: `000000`, `000100`, and `000213`
- Full session output: 214 left frames and 214 right frames
- Per-view image: `1280x720`, 8-bit RGB PNG

The complete 214-frame output is intentionally not committed. These samples
demonstrate the generated directory naming, frame numbering, resolution, and
left/right split.

`previews/` contains compressed 640x360 JPEG thumbnails for display. The
`images_rectified_left/` and `images_rectified_right/` directories contain the
original PNG outputs.
